# 🐄 智慧牧场管理系统（Dairy Farm Management System）

面向规模化奶牛场的轻量级管理系统：管理**奶牛档案、挤奶记录、健康与用药、繁殖周期**，
内置**发情/孕检/干奶/待产/用药提醒、奶量异常发现、休药期校验与违规混装拦截**。

技术栈：**Vue 3（无构建，CDN 本地化）+ FastAPI + SQLite + SQLAlchemy**，开箱即用。

## ✨ 功能一览

| 模块 | 能力 |
| --- | --- |
| 工作台 | 牛群结构、今日/昨日产量、近 14 天上市/废弃奶堆叠柱状图、待办提醒、异常清单 |
| 奶牛档案 | 耳标号、品种、胎次、牛舍、产犊/预产期、标定日产；检索、增删改 |
| 挤奶记录 | 早/午/晚三班产量与体细胞数（SCC）；废弃奶单独计量，不混入大罐产量 |
| 健康情况 | 体检/诊断/免疫、体温、严重程度、复查日、结案状态 |
| 用药管理 | 药品目录与默认休药期；选药自动套用休药期，可覆盖；下次用药提醒 |
| 发情与配种（繁殖周期） | 按牛串起发情→配种→多次孕检→妊娠终止→产犊完整周期，阶段驱动提醒，补录/更正自动说明影响 |

### 🔔 智能提醒（`/api/reminders`）

所有繁殖类提醒由“当前繁殖阶段”实时驱动，只围绕**当前有效周期**生成，
旧周期的孕检/配种结果不会再产生待办：

- **发情待配**：发情当日起 48 小时输精窗口（一旦登记配种即消失），逾期标红
- **返情观察**：当前配种后 18–24 天
- **妊娠检查**：当前配种后 35–42 天，超期标红（疑似复查不关闭窗口）
- **长期空怀**：配种 60 天无结论，或阴性孕检/妊娠终止对应配种超 60 天未复配
- **产后首配窗口**：产犊后 40–80 天未配种
- **干奶提醒**：预产期前 60 天（仅泌乳中妊娠牛）
- **待产预警**：预产期前 10 天 / 超期
- **续用药提醒**：用药疗程的下次用药日（±3 天）
- **健康复查**：未结案病历到达复查日
- **休药期进行中**：当日鲜奶必须废弃

### 💕 繁殖周期模型（核心）

以**只追加的事件流**（发情/配种/孕检/妊娠终止/产犊）为唯一真相源，按产犊自动划分周期：

- **按牛查看完整周期**：发情→返情复配（多次配种）→多次孕检（阳性/阴性/疑似复查）
  →妊娠终止（流产/死产/孕牛淘汰）→产犊，全部串在一条时间线上，历史周期永久保留。
- **当前阶段决定后续提醒**：阶段由全部有效事件按日期回放得到
  （发情待配 / 已配待检 / 妊娠中 / 产后空怀 / 空怀待配），不允许旧结果覆盖当前状态。
- **孕检结果与档案分离维护**：预产期只由“最近一次阳性孕检”维护（可手工校正，
  留空按配种日+280 天自动推算；更正配种日期会级联重算自动预产期）；
  最近产犊日只由产犊事件维护，档案表单只读。
- **产犊衔接新泌乳阶段**：登记产犊后本周期闭合、胎次可勾选 +1、牛群状态自动转“泌乳中”、
  预产期/待产提醒关闭、进入产后首配窗口；作废产犊事件上述变化全部自动回退。
- **补录/更正必须说明影响**：每次写入对比前后状态，返回并留痕“阶段/预产期/产犊日/胎次/
  提醒如何变化”，历史补录会明确提示“归入上一周期，当前状态不变”。
- **日期不完整不猜完成**：旧记录支持“仅年月 / 日期缺失”精度，只归档展示，
  绝不参与阶段、预产期和提醒计算。
- 错误事件用**作废（需填原因）**而非物理删除，旧发情表数据首次启动时一次性迁移为事件。

### 📉 奶量异常发现（`/api/anomalies`）

- 以异常日前 8–2 天的**同班次均值**为基线，单班下降 > 25% → 单班骤降
- **连续 ≥3 天**日产奶量下滑且累计 ≥15% → 持续下滑（只用完整三班日，今日早班不误报）
- **SCC ≥ 50 万 cells/mL** → 疑似乳房炎
- 多信号聚合到牛只并定级（高风险/需关注/观察）

### 🚫 休药期校验

- 规则：休药期含**用药当天**，`休药期截止日 = 用药日 + 休药天数`，**次日**鲜奶方可上市
- 录入挤奶前可调用 `POST /api/milkings/check-withdrawal` 预检（前端选牛即自动校验）
- 休药期内登记挤奶：**自动标记为废弃奶**并给出警告，从根本上杜绝违规混装
- 挤奶列表/仪表盘可筛查历史**违规混装**记录（休药期内却未废弃），一键补标废弃

## 🚀 快速开始

```bash
cd dairy-farm
pip install -r requirements.txt   # 或使用 run.sh 自动安装
python -m backend.seed            # 初始化 SQLite + 写入样例数据
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
# 或直接：bash run.sh
```

打开 <http://127.0.0.1:8000> ，Swagger 文档：<http://127.0.0.1:8000/docs>

数据库文件：`backend/data/dairy.db`（删除后重新执行 seed 即可重置）。

## 📁 目录结构

```
dairy-farm/
├── backend/
│   ├── main.py        # FastAPI 路由（CRUD + 仪表盘 + 校验）
│   ├── models.py      # SQLAlchemy 模型
│   ├── schemas.py     # Pydantic 模型
│   ├── services.py    # 提醒引擎 / 异常发现 / 休药期规则
│   ├── reproductive.py# 繁殖周期事件溯源、周期重建、阶段/提醒、补录影响
│   ├── seed.py        # 建库与样例数据
│   ├── database.py    # 引擎与会话
│   └── data/dairy.db  # SQLite（运行后生成）
├── frontend/
│   ├── index.html
│   ├── styles.css
│   ├── app.js         # Vue 3 单文件应用（工作台/5 大模块/弹窗表单）
│   └── vendor/vue.global.prod.js
├── requirements.txt
└── run.sh
```

## 🔌 主要 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/dashboard` | 仪表盘汇总 |
| GET | `/api/reminders` | 全部提醒（按紧急度排序） |
| GET | `/api/anomalies?days=7` | 奶量异常（按牛聚合） |
| GET/POST/PATCH/DELETE | `/api/cows[...]` | 奶牛档案 |
| GET/POST/PATCH/DELETE | `/api/milkings[...]` | 挤奶记录 |
| POST | `/api/milkings/check-withdrawal` | 录入前休药期预检 |
| GET/POST/PATCH/DELETE | `/api/health[...]` | 健康记录 |
| GET/POST | `/api/drugs` | 药品目录 |
| GET/POST/PATCH/DELETE | `/api/medications[...]` | 用药记录 |
| GET/POST/PATCH/DELETE | `/api/estruses[...]` | 旧发情/配种记录（只读迁移源，建议使用繁殖周期 API） |
| GET | `/api/repro/overview` | 全群当前繁殖阶段概览 |
| GET | `/api/repro/cows/{id}` | 单牛完整繁殖周期、不完整旧记录、变更影响留痕 |
| POST | `/api/repro/events` | 登记繁殖事件（支持 day/month/unknown 日期精度，返回影响说明） |
| PATCH | `/api/repro/events/{id}` | 更正事件（自动重算阶段/预产期并级联） |
| POST | `/api/repro/events/{id}/void` | 作废事件（需原因，胎次/状态/日期自动回退） |
| DELETE | `/api/repro/events/{id}` | 删除手工事件（旧档迁移事件只能作废） |

> 说明：系统为单机演示应用，未做登录鉴权；生产部署请置于内网并自行增加认证与 HTTPS。

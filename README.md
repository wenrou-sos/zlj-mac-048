# 🐄 智慧牧场管理系统（Dairy Farm Management System）

面向规模化奶牛场的轻量级管理系统：管理**奶牛档案、挤奶记录、健康与用药、发情配种**，
内置**发情/孕检/用药/待产提醒、奶量异常发现、休药期校验与违规混装拦截**，并提供
**岗位 + 牛舍范围的登录鉴权**（场长、兽医、挤奶员、只读人员、管理员）。

技术栈：**Vue 3（无构建，CDN 本地化）+ FastAPI + SQLite + SQLAlchemy**，开箱即用。

## 🔐 登录与权限模型

- **岗位（角色，可兼岗）**：一个用户可拥有多个岗位，权限为所有岗位并集。
- **牛舍数据范围**：管理员/场长为全场；兽医、挤奶员、只读人员只能访问被分配牛舍内的牛只数据
  （档案、挤奶、健康、用药、发情、提醒、异常、看板均按范围过滤）。
- **临时接管**：牛舍分配带 `生效日/截止日`，可安排未来生效、到期自动收回，无需当天手动改权限。
- **即时生效**：权限每请求实时从数据库计算，不做缓存；调岗、停用、退出、改密会**立即吊销其全部会话**。
- **防越权**：所有业务接口在服务端鉴权（登录态 + 权限码 + 牛舍归属 + 记录登记人），
  直接用 curl/Postman 访问接口同样被拦截；前端隐藏按钮仅为体验。
- **挤奶员仅能改/删本人登记的挤奶记录**；休药期违规补标废弃单独授权，兽医/挤奶员在本舍内可执行。

| 能力 | 管理员 admin | 场长 manager | 兽医 vet | 挤奶员 milker | 只读 viewer |
| --- | --- | --- | --- | --- | --- |
| 数据范围 | 全场 | 全场 | 负责牛舍 | 负责牛舍 | 负责牛舍 |
| 工作台/提醒/异常 | ✓ | ✓ | ✓(本舍) | ✓(本舍) | ✓(本舍) |
| 档案增删改、牛只跨舍调动 | ✓ | ✓ | — | — | — |
| 健康/用药/发情配种 | ✓ | ✓ | ✓(本舍) | — | — |
| 挤奶登记/改/删 | ✓ | ✓ | — | 仅本人记录 | — |
| 违规补标废弃 | ✓ | ✓ | ✓(本舍) | ✓(本舍) | — |
| 药品目录维护 | ✓ | ✓ | — | — | — |
| 牛舍管理 | ✓ | ✓ | — | — | — |
| 人员账号管理 | ✓ | 非管理员账号 | — | — | — |

> **防锁死**：系统始终至少保留一个启用中的管理员——停用/降级最后一个管理员会被后端拒绝（409）；
> 该校验在写锁事务内完成（SQLite `BEGIN IMMEDIATE` 串行化），**两个管理员并发各自停用账号时也只会成功一个**；
> 即使误操作，也可用命令行恢复：`python -m backend.auth_cli ensure-admin admin 新密码`。
> **换账号数据隔离**：退出、登录、会话失效会清空全部按范围缓存的业务数据并作废旧会话的在途响应，
> 切换到其他牛舍账号不会残留上一个账号看到的记录。
> 旧版本（无登录）数据库首次启动会**自动迁移**：补齐新表/新列、按牛只原"牛舍/群组"归并牛舍、
> 创建初始化管理员 `admin`（初始密码 `admin123`，可用环境变量 `DAIRY_ADMIN_PASSWORD` 覆盖）。

## ✨ 功能一览

| 模块 | 能力 |
| --- | --- |
| 登录与权限 | 岗位（场长/兽医/挤奶员/只读/管理员）+ 负责牛舍双重控制；兼岗并集；临时接管；服务端逐接口鉴权 |
| 工作台 | 牛群结构、今日/昨日产量、近 14 天上市/废弃奶堆叠柱状图、待办提醒、异常清单（按负责牛舍过滤） |
| 奶牛档案 | 耳标号、品种、胎次、牛舍、产犊/预产期、标定日产；检索、增删改 |
| 挤奶记录 | 早/午/晚三班产量与体细胞数（SCC）；废弃奶单独计量，不混入大罐产量；挤奶员仅能改删本人记录 |
| 健康情况 | 体检/诊断/免疫、体温、严重程度、复查日、结案状态 |
| 用药管理 | 药品目录与默认休药期；选药自动套用休药期，可覆盖；下次用药提醒 |
| 发情配种 | 发情发现方式/强度、冻精、配种员、孕检结果回填 |

### 🔔 智能提醒（`/api/reminders`）

- **发情待配**：发情当日起 48 小时输精窗口，逾期标红
- **返情观察**：配种后 18–24 天
- **妊娠检查**：配种后 35–42 天，超期标红
- **长期空怀**：配种 60 天无结果，或已判未孕
- **产后首配窗口**：产后 40–80 天未配种
- **续用药提醒**：用药疗程的下次用药日（±3 天）
- **健康复查**：未结案病历到达复查日
- **待产预警**：预产期前 10 天 / 超期
- **休药期进行中**：当日鲜奶必须废弃

### 📉 奶量异常发现（`/api/anomalies`）

- 以异常日前 8–2 天的**同班次均值**为基线，单班下降 > 25% → 单班骤降
- **连续 ≥3 天**日产奶量下滑且累计 ≥15% → 持续下滑（只用完整三班日，今日早班不误报）
- **SCC ≥ 50 万 cells/mL** → 疑似乳房炎
- 多信号聚合到牛只并定级（高风险/需关注/观察）

### 🚫 休药期校验

- 规则：休药期含**用药当天**，`休药期截止日 = 用药日 + 休药天数`，**次日**鲜奶方可上市
- 录入挤奶前可调用 `POST /api/milkings/check-withdrawal` 预检（前端选牛即自动校验）
- 休药期内登记挤奶：**自动标记为废弃奶**并给出警告，从根本上杜绝违规混装
- 挤奶列表/仪表盘可筛查历史**违规混装**记录（休药期内却未废弃），一键补标废弃

## 🚀 快速开始

```bash
cd dairy-farm
pip install -r requirements.txt   # 或使用 run.sh 自动安装
python -m backend.seed            # 初始化 SQLite + 写入样例数据
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
# 或直接：bash run.sh
```

打开 <http://127.0.0.1:8000> ，Swagger 文档：<http://127.0.0.1:8000/docs>

数据库文件：`backend/data/dairy.db`（删除后重新执行 seed 即可重置）。

### 命令行管理员工具（初始化/找回入口）

```bash
python -m backend.auth_cli list                       # 列出全部账号
python -m backend.auth_cli ensure-admin admin 新密码   # 确保一个启用管理员（不存在则创建）
python -m backend.auth_cli reset-password 用户名 新密码 # 重置任意用户密码并立即启用
```

应用启动时也会保证至少存在一个启用中的管理员（旧库自动迁移后默认 `admin/admin123`），
因此**不会因停用最后一个管理员而把系统锁死**。

```

│   ├── main.py        # FastAPI 路由（CRUD + 仪表盘 + 校验 + 鉴权）
```

## 🔌 主要 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/auth/login` · `/logout` | 登录（HttpOnly Cookie 会话，12h）/ 退出 |
| GET | `/api/auth/me` · POST `/api/auth/change-password` | 当前用户权限与范围 / 改密 |
| GET/POST/PATCH | `/api/sheds[...]` | 牛舍管理（管理员/场长） |
| GET/POST/PATCH | `/api/users[...]` | 人员、岗位、牛舍分配、停用（场长不可管理管理员） |
| GET | `/api/dashboard` | 仪表盘汇总（按牛舍范围） |
| GET | `/api/reminders` | 全部提醒（按牛舍范围） |
| GET | `/api/anomalies?days=7` | 奶量异常（按牛舍范围） |
| GET/POST/PATCH/DELETE | `/api/cows[...]` | 奶牛档案 |
| GET/POST/PATCH/DELETE | `/api/milkings[...]` | 挤奶记录 |
| POST | `/api/milkings/{id}/discard` | 违规混装一键补标废弃 |
| POST | `/api/milkings/check-withdrawal` | 录入前休药期预检 |
| GET/POST/PATCH/DELETE | `/api/health[...]` | 健康记录 |
| GET/POST | `/api/drugs` | 药品目录 |
| GET/POST/PATCH/DELETE | `/api/medications[...]` | 用药记录 |
| GET/POST/PATCH/DELETE | `/api/estruses[...]` | 发情/配种记录 |

除登录与静态资源外，所有 `/api/*` 均需登录；会话支持 HttpOnly Cookie（浏览器）
或 `Authorization: Bearer <token>`（直连接口/脚本）。

> 部署提示：口令使用 PBKDF2-SHA256 加盐哈希存储；系统默认无注册入口，账号由管理员在
> 「人员与权限」页维护。生产环境请置于内网或反向代理后并启用 HTTPS。

# 🐄 智慧牧场管理系统（Dairy Farm Management System）

面向规模化奶牛场的轻量级管理系统：管理**奶牛档案、挤奶记录、健康与用药、发情配种**，
内置**发情/孕检/用药/待产提醒、奶量异常发现、休药期校验与违规混装拦截**。

技术栈：**Vue 3（无构建，CDN 本地化）+ FastAPI + SQLite + SQLAlchemy**，开箱即用。

## ✨ 功能一览

| 模块 | 能力 |
| --- | --- |
| 工作台 | 牛群结构、今日/昨日产量、近 14 天上市/废弃奶堆叠柱状图、班次待办（认领/指派/延期/完成）、异常清单 |
| 待办交班 | 待办看板（休药警告/已更新/待认领/处理中/已完成失效）、负责人指派、延期原因、处理结果、操作流水、一键交班带到下一班 |
| 奶牛档案 | 耳标号、品种、胎次、牛舍、产犊/预产期、标定日产；检索、增删改 |
| 挤奶记录 | 早/午/晚三班产量与体细胞数（SCC）；废弃奶单独计量，不混入大罐产量 |
| 健康情况 | 体检/诊断/免疫、体温、严重程度、复查日、结案状态 |
| 用药管理 | 药品目录与默认休药期；选药自动套用休药期，可覆盖；下次用药提醒 |
| 发情配种 | 发情发现方式/强度、冻精、配种员、孕检结果回填 |

### 📋 待办认领与交班（`/api/tasks`）

提醒不再"刷新即重建"，而是以**持久化工单**形式运行：

- **稳定指纹去重（幂等派单）**：引擎为每个业务事项计算 `dedup_key`（如 `repro:7`、`withdrawal:3`），
  刷新页面、服务重启都只做"对账"，同一件事绝不重复派出；负责人、延期原因、处理记录全程保留。
- **认领 / 指派**：顶栏选择值班人（免登录，直接维护姓名）后可"我认领"，或指派给名单里任意人；
  支持改名、停用。认领采用 **version 乐观锁**，两人同时认领时后提交者收到 **409 冲突**，
  弹窗显示先认领的人，列表即时刷新为最新状态。
- **延期与处理结果**：延期必须填写原因并可改期；完成时记录处理结果，全部写入操作流水。
- **交班续传**："交班给下一班"生成交班单（交班人/接班人/备注/未完成清单），
  所有未完成事项按指纹带到下一班并记录 `carried` 流水与续传班次数。
- **源记录变更可解释**：源记录被修改 → 待办标红"🔁 已更新·待确认"（内容已刷新、负责人保留），
  确认后恢复处理；源记录删除/牛只离场/业务已办结 → 标记"⛓ 已失效/已办结"并留痕，不会悄悄消失。
- **安全红线**：
  - **续用药、孕检**待办的"完成"必须落到真实登记——系统会同步写用药「已执行」或回填**孕检结果**，
    仅在待办上点完成会被拒绝（未孕登记后事项转长期空怀继续跟进，不虚假办结）；
  - **休药警告**在有效期内**不可认领、不可延期、不可完成**，始终置顶红色展示，到期由系统自动解除，
    不会被任何操作隐藏。

### 🔔 智能提醒（`/api/reminders`）

- **发情待配**：发情当日起 48 小时输精窗口，逾期标红
- **返情观察**：配种后 18–24 天
- **妊娠检查**：配种后 35–42 天，超期标红
- **长期空怀**：配种 60 天无结果，或已判未孕
- **产后首配窗口**：产后 40–80 天未配种
- **续用药提醒**：用药疗程的下次用药日（±3 天）
- **健康复查**：未结案病历到达复查日
- **待产预警**：预产期前 10 天 / 超期
- **休药期进行中**：当日鲜奶必须废弃

### 📉 奶量异常发现（`/api/anomalies`）

- 以异常日前 8–2 天的**同班次均值**为基线，单班下降 > 25% → 单班骤降
- **连续 ≥3 天**日产奶量下滑且累计 ≥15% → 持续下滑（只用完整三班日，今日早班不误报）
- **SCC ≥ 50 万 cells/mL** → 疑似乳房炎
- 多信号聚合到牛只并定级（高风险/需关注/观察）

### 🚫 休药期校验

- 规则：休药期含**用药当天**，`休药期截止日 = 用药日 + 休药天数`，**次日**鲜奶方可上市
- 录入挤奶前可调用 `POST /api/milkings/check-withdrawal` 预检（前端选牛即自动校验）
- 休药期内登记挤奶：**自动标记为废弃奶**并给出警告，从根本上杜绝违规混装
- 挤奶列表/仪表盘可筛查历史**违规混装**记录（休药期内却未废弃），一键补标废弃

## 🚀 快速开始

```bash
cd dairy-farm
pip install -r requirements.txt   # 或使用 run.sh 自动安装
python -m backend.seed            # 初始化 SQLite + 写入样例数据
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
# 或直接：bash run.sh
```

打开 <http://127.0.0.1:8000> ，Swagger 文档：<http://127.0.0.1:8000/docs>

数据库文件：`backend/data/dairy.db`（删除后重新执行 seed 即可重置）。

## 📁 目录结构

```
dairy-farm/
├── backend/
│   ├── main.py        # FastAPI 路由（CRUD + 仪表盘 + 待办/交班 + 校验）
│   ├── models.py      # SQLAlchemy 模型（含待办/流水/人员/交班单）
│   ├── schemas.py     # Pydantic 模型
│   ├── services.py    # 提醒引擎（稳定指纹）/ 异常发现 / 休药期规则
│   ├── tasks.py       # 待办对账（幂等派单）、认领/延期/完成、乐观锁、交班
│   ├── seed.py        # 建库与样例数据
│   ├── database.py    # 引擎与会话
│   └── data/dairy.db  # SQLite（运行后生成）
├── frontend/
│   ├── index.html
│   ├── styles.css
│   ├── app.js         # Vue 3 单文件应用（工作台/5 大模块/弹窗表单）
│   └── vendor/vue.global.prod.js
├── requirements.txt
└── run.sh
```

## 🔌 主要 API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/dashboard` | 仪表盘汇总（含待办/休药警告计数） |
| GET | `/api/reminders` | 对账后返回当前活跃待办（幂等，刷新不重复派单） |
| GET | `/api/tasks?scope=` | 待办列表：active/open/mine/closed/all |
| GET/POST | `/api/tasks/{id}/...` | `claim` 认领、`assign` 指派、`postpone` 延期、`complete` 完成（可带真实登记）、`acknowledge-update` 确认更新、`reopen` 重开、`events` 流水；写操作带 `version` 乐观锁，冲突返回 409 |
| GET/POST/PATCH | `/api/persons` | 值班人员名单（免登录，直接增/改名/停用） |
| POST/GET | `/api/handovers` | 生成交班单 / 查看交班记录 |
| GET | `/api/shift/current` | 当前班次（早/午/晚） |
| GET | `/api/anomalies?days=7` | 奶量异常（按牛聚合） |
| GET/POST/PATCH/DELETE | `/api/cows[...]` | 奶牛档案 |
| GET/POST/PATCH/DELETE | `/api/milkings[...]` | 挤奶记录 |
| POST | `/api/milkings/check-withdrawal` | 录入前休药期预检 |
| GET/POST/PATCH/DELETE | `/api/health[...]` | 健康记录 |
| GET/POST | `/api/drugs` | 药品目录 |
| GET/POST/PATCH/DELETE | `/api/medications[...]` | 用药记录 |
| GET/POST/PATCH/DELETE | `/api/estruses[...]` | 发情/配种记录 |

> 说明：系统为单机演示应用，未做登录鉴权；生产部署请置于内网并自行增加认证与 HTTPS。
